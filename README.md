# PayProof (ניהול מנויים, אחריות וקבלות) 🛡️

**PayProof** היא אפליקציית פינטק מודרנית לניהול ומעקב אחר מנויים חודשיים, תעודות אחריות וקבלות דיגיטליות. האפליקציה נבנתה במיוחד עבור השוק הישראלי עם תמיכה מלאה בכתיבה מימין לשמאל (RTL), ומציעה ממשק משתמש עתידני, אינטראקטיבי ואינטואיטיבי המבוסס על עקרונות עיצוב מתקדמים (Glassmorphism & Bento Grid).

---

## 🚀 תכונות עיקריות (Features)

* 📊 **לוח בקרה חכם (Dashboard)**:
  - פריסת **Bento Grid** עתידנית עם כרטיסיות זכוכית זוהרות.
  - כרטיסי סיכום עם אינדיקטורים צבעוניים (מנויים פעילים, קבלות, פגי תוקף).
  - עוזר בינה מלאכותית (AI Assistant) מובנה המנתח את מצב המנויים ומציע הצעות ייעול.
  - התראות על פריטים המסתיימים בקרוב.

* 💳 **ניהול מנויים (Subscriptions)**:
  - מעקב פיננסי חודשי אחר מנויים פעילים (מחיר, תאריך חידוש וסטטוס).
  - חישוב ימים שנותרו ואינדיקציה באמצעות תגיות זוהרות (ירוק, צהוב, אדום).
  - שמירה מקומית מאובטחת (`LocalStorage`) מוכנה לסנכרון עתידי.

* 🛡️ **מעקב אחריות מוצרים (Warranties)**:
  - ניהול מלא של תקופות אחריות למוצרים שנרכשו.
  - סנכרון מלא מול בסיס הנתונים של **Supabase**.
  - קישור קבלות מתוך שרת האחסון (Storage) ישירות לפריט האחריות.

* 📄 **ארכיון קבלות ממוחשב (Receipts)**:
  - העלאת קבצים מונפשת ומעוצבת.
  - תצוגה מקדימה (Preview) ייחודית המדמה קבלה ממוחשבת מורחבת של הפריט.
  - חישוב נפח אחסון מנוצל בזמן אמת.

* 👥 **ניהול משתמשים ומנהלי מערכת (User Management)**:
  - עמוד ניהול מתקדם למנהלים (Admins).
  - טבלת זכוכית אינטראקטיבית למחשב, וכרטיסיות רספונסיביות המותאמות במיוחד למובייל.
  - אפשרות לחסימה/אישור משתמשים ושינוי תפקידם (מנהל/משתמש).

* 🔐 **אבטחה והזדהות (Auth)**:
  - התחברות מאובטחת באמצעות דוא"ל וסיסמה.
  - הזדהות מהירה באמצעות חשבון גוגל (**Google OAuth**) בלחיצה אחת.
  - תהליך שחזור ואיפוס סיסמה מאובטח מונחה טריגרים.

## 🛠️ טכנולוגיות (Tech Stack)

- **Frontend**: React 18, Vite, Tailwind CSS (v3).
- **Icons**: Lucide React.
- **Backend & Database**: Supabase (PostgreSQL, Auth, RLS, Trigger, Storage).
- **State Management**: React Hooks + LocalStorage.
- **Hosting**: Vercel.

## 🎨 מערכת העיצוב (Design System)

האפליקציה משתמשת בשפת עיצוב ייחודית הכוללת:
* **ערכת נושא כהה**: צבעי רקע בחלל עמוק (`#050914`).
* **Glassmorphism**: שימוש נרחב בכיתוב חצי שקוף, טשטוש רקע מוגבר וגבולות זוהרים ברוחב 1 פיקסל.
* **טיפוגרפיה**: פונט `Outfit` לכותרות תצוגה ופונט `Inter` לטקסט שוטף.
* **אפקט אורורה (Aurora)**: תאורת אווירה פנימית בצבעי סגול וטורקיז המונפשת ברקע.

## 💻 הוראות הפעלה והתקנה (Getting Started)

### 1. דרישות קדם (Prerequisites)
ודא שמותקנת אצלך סביבת Node.js (גרסה 16 ומעלה).

### 2. התקנת תלויות
שבט את הפרויקט והרצ את הפקודה הבאה בתיקיית השורש:
```bash
npm install
```

### 3. הגדרת משתני סביבה (.env)
צור קובץ בשם `.env` בתיקיית השורש והזן את הפרטים הבאים (שים לב: הקובץ מוגדר ב-`.gitignore` כדי למנוע דליפת סודות ל-Git):
```env
VITE_SUPABASE_URL=https://your-project-ref.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-public-key
VITE_GOOGLE_CLIENT_ID=your-google-client-id
VITE_GOOGLE_CLIENT_SECRET=your-google-client-secret
```

### 4. הרצה במצב פיתוח
```bash
npm run dev
```
האפליקציה תהיה זמינה בכתובת: `http://localhost:5173`

### 5. בניית גרסת הפצה (Build)
```bash
npm run build
```

## 🗄️ הגדרת מסד הנתונים בסופרבייס (Supabase Schema Setup)

על מנת להקים את בסיס הנתונים עבור האפליקציה, הרץ את סקריפט ה-SQL הבא בתוך ה-**SQL Editor** ב-Supabase:

```sql
-- יצירת טבלת פרופילי משתמשים (profiles)
create table if not exists public.profiles (
  id uuid references auth.users on delete cascade not null primary key,
  first_name text,
  last_name text,
  email text,
  mobile text,
  role text default 'user' check (role in ('user', 'admin')),
  status text default 'approved' check (status in ('pending', 'approved', 'blocked')),
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- יצירת טבלת מוצרים ואחריות (warranties)
create table if not exists public.warranties (
  id bigint generated by default as identity primary key,
  user_id uuid references auth.users on delete cascade not null,
  product_name text not null,
  store text,
  purchase_date date,
  expiry_date date,
  serial_number text,
  receipt_url text,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- הפעלת מנגנון אבטחה ברמת שורה (RLS)
alter table public.profiles enable row level security;
alter table public.warranties enable row level security;

-- הענקת גישה כללית לסכמה הציבורית
grant usage on schema public to anon, authenticated;
grant select, insert, update, delete on public.profiles to anon, authenticated, service_role;
grant select, insert, update, delete on public.warranties to anon, authenticated, service_role;
grant usage, select on all sequences in schema public to anon, authenticated, service_role;

-- פונקציית עזר לבדיקת מנהל מערכת (Admin Check Helper)
create or replace function public.is_admin()
returns boolean as $$
declare
  user_role text;
begin
  select role into user_role from public.profiles where id = auth.uid();
  return (user_role = 'admin');
end;
$$ language plpgsql security definer;

-- חוקי RLS לטבלת פרופילים
create policy "Allow owners to view profiles" on public.profiles for select using (auth.uid() = id or public.is_admin());
create policy "Allow owners to update profiles" on public.profiles for update using (auth.uid() = id or public.is_admin());
create policy "Allow admins to manage profiles" on public.profiles for all using (public.is_admin());

-- חוקי RLS לטבלת אחריות
create policy "Allow owners to manage warranties" on public.warranties for all using (auth.uid() = user_id or public.is_admin());

-- יצירת טריגר לפרופיל אוטומטי בעת רישום (או כניסה עם Google)
create or replace function public.handle_new_user()
returns trigger as $$
begin
  insert into public.profiles (id, email, first_name, last_name, role, status)
  values (
    new.id,
    new.email,
    coalesce(new.raw_user_meta_data->>'given_name', new.raw_user_meta_data->>'name', split_part(new.email, '@', 1)),
    coalesce(new.raw_user_meta_data->>'family_name', ''),
    'user',
    'approved'
  );
  return new;
end;
$$ language plpgsql security definer;

create trigger on_auth_user_created
  after insert on auth.users
  for each row execute function public.handle_new_user();

-- יצירת תיקיית אחסון ציבורית לקבלות (Storage Bucket)
insert into storage.buckets (id, name, public) values ('receipts', 'receipts', true) on conflict (id) do nothing;

-- חוקי אבטחה ב-Storage לקבלות
create policy "Allow authenticated users to upload receipts" on storage.objects for insert to authenticated with check (bucket_id = 'receipts');
create policy "Allow public to view receipts" on storage.objects for select to public using (bucket_id = 'receipts');
```
